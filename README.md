
# WargaReport
A platform for submitting reports or complaints regarding public facilities.

### Fitur
- Melaporkan kerusakan fasilitas umum
- Melihat laporan terbaru pada live feed
- Melacak laporan menggunakan ID pelaporan
- Melihat detail, status, dan perkembangan laporan
- Registrasi dan masuk ke akun
- Melihat riwayat dan notifikasi pengguna
- Menggunakan autentikasi pada halaman pengguna tertentu
- Halaman penjelasan alur pelaporan
